# Clawrchive

Market research compiled periodically covering topics such as stocks, politics, and more.

## Directory Structure

Files are organized as follows:

```
<topic>/<year (yyyy)>/<month (MM)>/<day (dd)>
```

Each day directory contains Markdown files for that day's content:

- `summary.md` — general overview or summary
- `research.md` — dense research notes
- `sources.md` — source links and references

### Example

```
stocks/2026/05/25/summary.md
stocks/2026/05/25/research.md
stocks/2026/05/25/sources.md
politics/2026/05/25/summary.md
```
