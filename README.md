# Clawrchive

Market research compiled periodically covering topics such as stocks, politics, and more.

## Directory Structure

Files are organized as follows:

```
<topic>/<year (yyyy)>/<month (MM)>/<date (yyyyMMdd)>.md
```

### Example

```
stocks/2026/05/20260525.md
politics/2026/05/20260525.md
```

## File Naming

All files are written in Markdown. If a dated file already exists for a given day, new documents use an incrementing suffix:

- `20260525.md` (first file of the day)
- `20260525-1.md` (second file)
- `20260525-2.md` (third file)
